## 1. 결론

**ToF(VL53L0X)를 팔 모터부에 다는 것은 틀렸다.** ToF 4개와 TCA9548A는 셀의 고정 프레임에 단다. 위치는 카세트 도크 아래, 대차 받침 위, 전장함이다.

**R축(공압 실린더 2개 병렬)으로는 R85를 할 수 없다.** 병렬이면 행정이 실린더 1개분(실측 62mm)이라 대차 적재 T9(R85)가 불가능하다. 받침 위치만 당겨서는 해결되지 않는다. 포크가 가득 찬 카세트와 겹치기 때문이다. 해결안 A(받침을 당기고 대차를 물림)와 B(직렬 2단 재구성)는 3.3절에 있고, A6 실측 뒤 고른다.

팔에 붙는 센서는 EE-SX670(θ·Z 원점·리밋, Z 선회 높이 S9, R 후진·도달 S3·S7)과 기존 S4뿐이다. EE-SX670도 모터축에 달지 않는다. 각 축의 출력측에 도그를 붙이고, 그 맞은편의 정지 부품에 센서를 단다. 출력측은 θ가 회전 원판, Z가 캐리지, R이 포크 슬라이더다.

### 1.1 ToF를 팔에 달면 안 되는 이유

'모터부'는 두 곳이다. θ 모터 브래킷은 베이스판 위에 있는 고정측이다. Z 모터 박스, 캐리지, R은 움직이는 쪽이다.

| 장착 위치 | 문제 | 근거 |
|---|---|---|
| θ 모터 브래킷 (고정측) | 배선은 괜찮지만 볼 대상이 없다 | 베이스 높이라서 슬롯(z190~264)과 대차 받침을 볼 수 없다. 한 방위만 본다 [추정: 브래킷 높이 미측정] |
| Z 모터 박스·캐리지·R (이동측) | 슬롯을 구분하지 못한다 | 빔 지름 D = 2·d·tan12.5° = 0.443·d [계산]. 수평 85mm에서 D≈38mm라서 피치 18mm 슬롯 2칸을 덮는다. 웨이퍼 끝면 2mm 띠는 빔 면적의 최대 약 7%다 [계산] |
| 〃 | 오차가 웨이퍼 두께(2mm, 가정)보다 크다 | 1σ는 33ms에서 4%(흰 88%)~7%(회색 17%), 200ms에서 <3%다 [외부자료: ST DS11555 Table 13, 70~120cm 조건]. 50~250mm로 환산하면 1σ 2~18mm다. 150mm 미만은 데이터시트에 규정이 없다 [불명] |
| 〃 | S4(포크 위 웨이퍼)를 대신하지 못한다 | 포크 위 웨이퍼는 1.5mm 거리에 있다. VL53L0X 최소 거리는 약 30mm다(모듈 판매처 표기, ST 데이터시트 미규정) |
| 〃 | 축 위치 확인용으로 쓸 수 없다 | Z 100~280mm에서 1σ 4~20mm다. S4 여유는 0.5~1mm, 삽입 틈은 3.0mm다(`r9_README.md`) |
| 〃 | 배선이 가장 나빠진다 | I2C 선이 θ 270° 케이블 루프와 Z 체인을 지나 1.5~2.5m가 된다 [추정]. Z 모터의 24V·STEP 선과 같은 다발로 간다. 2.5m면 상승시간이 100kHz 한계에 닿는다(5.3절) |
| 〃 | 측정 기회가 적다 | 팔이 그 스테이션에 가 있을 때만 잴 수 있다 |

### 1.2 원점센서를 모터축에 달면 안 되는 이유

- 모터축 기준으로는 모터와 팔 사이에서 생기는 벨트·기어 이빨 튐을 잡지 못한다. R9 시뮬 고장 `belt_skip`이 이 경우다.
- ST-NK1748E 내장 엔코더(1000CPR)도 모터축만 본다.
- 아두이노는 엔코더 값을 읽지 못한다. AL도 현재 배선되어 있지 않다(`arm_stepper_control.ino` 20행 "EN/AL 미사용", 30~32행 "나중에 AL(경보)선을 읽어").
- 따라서 지금은 스텝 손실을 감지할 수단이 없다. AL 배선(5.5절)은 이 문서가 새로 추가하는 사항이다.

### 1.4 먼저 결정할 것

1. **R85 해결 방법.** R은 공압 실린더 2개 병렬로 확정됐다. 행정 62로는 R85(대차 받침)를 할 수 없고, 받침만 당기면 포크가 가득 찬 카세트와 겹친다(3.3절). A(받침을 당기고 T11 뒤 대차를 물리는 인터록 추가)와 B(직렬 2단 재구성)를 A6 실측 뒤 비교해 정한다. 어느 안이든 TOF-CART 위치와 대차 적재 수치(T9~T13)가 바뀐다. B나 C를 고르면 R 띠 길이(R85면 L ≥ 88), S7, S8 추가, 타임아웃, EE-SX670 수량, 전원표, 핀맵, 케이블 B 심수도 다시 정한다.
2. **도크 바닥과 카세트 자체 바닥.** 빔 구간(r226~245)에서 열려 있어야 한다. 카세트 상부에 기준면(판)이 있는지도 확인한다. 카세트 바닥이 막혀 있으면 순환하는 모든 카세트에 Ø34 구멍을 뚫어야 한다.
3. **θ 기구 치수.** 전달 방식(벨트/기어)과 감속비 i를 확인한다. 피니언·모터 브래킷 꼭대기와 원판 밑면 사이 틈 g도 잰다. 기둥이 비어 있는지(케이블 경로)도 본다.

### 1.5 이 안의 약점

| # | 약점 | 영향과 대응 |
|---|---|---|
| 1 | 하부 ToF의 슬롯 판정 성능이 검증되지 않았다 | 근거리 정확도는 데이터시트에 규정이 없다. 33ms 1σ로는 슬롯 5에서 판정창 ±5mm가 약 ±1σ다. 현장 시험 B13~B15를 통과하기 전까지 [불명]이다. 200ms 모드, 센서별 2점 보정, 이벤트 전후 차분 판정을 기본으로 한다. 불합격이면 차분 판정(Δ18mm)에만 쓴다 |
| 2 | 도크와 카세트 바닥이 열려 있어야 한다 | 막혀 있으면 순환 카세트를 전부 가공해야 하므로 하향안 대비 이점이 줄어든다. 불가능하면 4.7절로 바꾼다 |
| 3 | 빈 카세트 판정에 기준면이 필요하다 | IN/NG 카세트 상부 형상은 [불명]이다. 기준면이 없으면 DOCK 스위치 2개를 달고 '신호 없음 = 알람'으로 운용한다 |
| 4 | 하부 ToF가 선회 통로 바로 아래에 있다 | 센서면 z140과 운반 웨이퍼 하면(Z95일 때 160.5) 사이 여유는 20mm다. CAD 간섭 확인이 필요하다 |
| 5 | θ 회전부에 도그 3층과 스토퍼 핀이 들어간다 | 도그는 전 방위를 쓴다. 피니언, 모터 브래킷, 센서 본체, 캐리지(Z95)와 높이로 분리해야 한다. g를 재기 전에는 성립 여부가 [불명]이다 |
| 6 | 튐 검출에 남는 구멍이 있다 | S1·S10 래치로도 T3(−40→0, 빈 포크) 구간의 튐은 T4 전에 잡지 못한다 |
| 7 | S1 정의가 바뀐다 | 섹터 + 엣지 래치는 현행 `abs(wrap_deg(theta)) <= 0.5`와 다르다. 시뮬과 펌웨어를 고쳐야 한다(8.3절) |
| 8 | 센서선, 모터선, 공압 튜브가 θ 케이블 경로를 지난다 | Z·R(S3·S7)·S4·S9 센서선, Z 모터선, R 공압 튜브 2가닥이 θ 270° 경로를 지난다. 경로는 [확인 필요]다 |
| 9 | 제어기 하나에 부하가 몰린다 | Z 10mm/s ÷ 리드 2mm/rev × 1000 step/rev = 5000 step/s다 [계산]. 16MHz AVR에서 AccelStepper 한계는 약 4000 step/s다 [기억값]. 블로킹 ToF 읽기(약 33ms)는 `run()` 호출을 끊어, 스텝이 감속 없이 멎는다. 그래서 **ToF I2C 통신은 모든 축이 정지했을 때만** 한다 |
| 10 | θ 기계 스토퍼가 없고 AL도 배선되지 않았다 | 벨트 구동이면 스토퍼에 걸려도 경보 없이 벨트만 튈 수 있다 |
| 11 | S6 엣지에서 스토퍼까지 7°뿐이다 | 60°/s에서 제동 거리는 0.9·i deg다 [계산]. i ≥ 8이면 7°를 넘는다 |
| 12 | 부품을 되돌릴 수 없다 | EE-SX670과 커넥터는 반품 불가다. EE-1001-1은 케이블이 없는 커넥터 단품이다 |
| 13 | Z 바닥 보호 수단이 약하다 | AL이 배선되지 않은 상태에서 S2 OUT이 GND와 단락되면, 바닥 충돌을 막는 것은 S9 기준 탐색 한도뿐이다 |
| 14 | **R85가 불가능하다** | 병렬 실린더 행정 62. 받침만 당기면 R0 포크(r203)가 카세트 웨이퍼와 17.5mm 겹친다. 대안 A(대차 물러남 인터록) 또는 B(직렬 2단)가 필요하다(3.3절) |
| 15 | R51 스토퍼가 풀리는 경우 | 풀려서 R62까지 나가면 포크 끝이 R265가 되어 크래들 허브(R262~, V9 기록)와 부딪힐 수 있다. 창형 S7(R49~53에서만 LOW)이 '도달 아님'으로 잡는다. 잠금 너트와 B12로 함께 막는다 |
| 16 | 병렬 실린더 동기 | 실린더끼리 서로 맞춰 움직이지 않아, 가이드가 없으면 연결판이 비틀려 걸린다(가이드 유무 [확인 필요]) |
| 17 | **SMPS를 꺼도 R이 멈추지 않는다** (공압 E-STOP 제외, 사용자 결정) | SMPS 스위치는 스테퍼 24V만 끊는다. 더블 솔레노이드는 코일 전원이 끊겨도 스풀과 공급압이 그대로라 실린더가 행정 끝까지 간다. R을 멈추는 방법은 **수동 차단·배기 밸브를 손으로 닫는 것뿐이다.** 이 밸브를 SMPS 스위치 옆에 둔다. Z는 리드스크루가 스스로 잠기지 않으면 떨어진다(B27). 공급압 저하는 S3·S7 기동 확인·타임아웃 알람으로만 드러난다 |

### 3.1 θ: S1(원점), S6(과주행), S10(통과 점검), 기계 스토퍼

**S1을 좁은 탭 대신 섹터 도그로 바꾼다.** 이유는 두 가지다.

1. 원점 0°가 범위 −90~180의 중간에 있다. 좁은 탭으로는 전원을 켰을 때 어느 쪽으로 찾아야 할지 모른다.
2. ±0.5° 창은 반경 50mm에서 호 0.87mm, 100mm에서 1.75mm다 [계산]. 이 폭이 표준 감지물체 2×0.8mm [기억값]와 비슷해서 설계로 보장하기 어렵다.

**전체 각도의 센서 상태** (# = 차광 = HIGH. STN = 스테이션, SW = 소프트 범위. 열 간격은 비례가 아님)

```

      |     |     |     |     |     |     |     |     |     |     |     |     |
S6    ######                                                            ######
S1    ##############################
S10                     ########################            ##################
STN               CART        OK          NG          INSP        IN
```

#### 도그 치수 [제안]

| 항목 | S1 | S6 | S10 |
|---|---|---|---|
| 차광 구간 | θ ∈ [−110, +3] (기계상 −100까지만 쓰임) | θ ≥ +183 또는 θ ≤ −93 | θ ∈ [−87, +90] ∪ [+150, 끝] |
| 호 각도 | 113° | 84° | 177° + 50° (2조각) |
| 층 | 1층 | 2층 | 3층 |
| 재질 | 알루미늄 1.5mm. 슬롯 5mm 안에서 양쪽 여유 1.75mm | 같음 | 같음 |
| 삽입 깊이 | 광축보다 1.5mm 이상 더 들어감. 광축 위치는 외형도로 [확인 필요] | 같음 | 같음 |

- θ 증가 방향은 반시계다(README "위에서 볼 때 시계방향 180→120→60→0" 기준).
- S6는 S1과 같은 층에 둘 수 없다. 같은 층이면 S1이 S6 도그를 보는 구간이 84°인데, 범위 밖에 남는 각도는 70°뿐이다.
- 3D 프린트 도그는 940nm IR이 샐 수 있다 [추정]. 금속을 쓰거나, 프린트라면 검정 2mm 이상이나 알루미늄 테이프를 쓴다.
- 선택 근거: S6는 탭 2개 대신 84° 섹터로 한다. 범위를 넘은 상태가 유지되므로 전원을 다시 켜도 알 수 있다.

#### 도그 링 배치 조건 (성립 조건)

- 도그는 θ와 함께 돌아 전 방위를 쓴다. 쓸고 지나가는 범위는 S1 403°, S6 374°다 [계산]. 스토퍼 핀은 290°를 쓴다. 그래서 센서를 모터 반대편 방위에 두어도 도그는 반드시 피니언·모터 위를 지나간다.
- S1, S6, S10 층과 스토퍼 핀 층은 높이로 서로 분리한다. 각 층이 피니언, 모터 브래킷 꼭대기, 다른 층의 센서 본체, Z95 캐리지 밑면과 닿으면 안 된다. 층 간격은 센서 몸체 높이 + 여유로 정한다 [확인 필요: EE-SX670 외형도].
- 반경만 다르게 해서 층을 나눌 수는 없다. 바깥 트랙까지 닿는 판은 안쪽 트랙도 덮기 때문이다.
- 21.png에서 피니언 윗면은 원판 밑면 바로 아래에 있다 [추정]. 원판 밑면에 플랜지를 붙이면 피니언과 간섭할 가능성이 크다. 그래서 도그 링을 원판 **외주 측면**에 반경 방향 나사로 고정해 피니언보다 높게 둔다 [제안].
- 스토퍼 블록(약 70°)은 핀이 지나가지 않는 유일한 구간이다. 피니언·모터 방위에 겹쳐 두는 것을 검토한다.

- **슬롯 판정 가능 여부는 현장 시험 B13~B15 전까지 [불명]이다.** 반피치는 9mm다. 33ms 흰색 기준으로 슬롯 5에서 판정창 ±5mm는 약 ±1σ다. 단일 측정의 약 30%가 판정 불가가 된다 [계산].
- 기본 측정 방식은 다음과 같다.
  - High accuracy(200ms) 2~3회의 중앙값을 쓴다.
  - 센서별 오프셋 2점 보정을 필수로 한다. 개체 간 오프셋은 중앙값으로 줄지 않는다.
  - 집기·넣기 판정은 같은 센서의 **전후 차분**(Δ = ±18mm)으로 한다. 차분을 쓰면 오프셋이 상쇄된다.
- 받침 이빨과의 간섭: 이빨 안쪽 끝을 웨이퍼 중심에서 약 45mm로 가정한다 [추정]. 슬롯 5에서 빔 반경 27 + 축 공차 3 + 놓임 공차 5 = 35mm이므로 여유는 10mm다.
- 바닥 구멍: Ø = 2·(z_hole − z_s)·tan12.5° + 2·(놓임 5 + 축 3) = 17.7 + 16 → **Ø34 이상**이다 [계산].
- 뒤 베이스: V9처럼 x250부터라면 빔 가장자리가 244.4 + 3 + 5 = 252.4 > 250이 되어 걸린다. R9 형상은 [불명]이다.
- 센서면 상한: Z95에서 운반 웨이퍼 하면은 160.5다. 센서면 140과의 수직 여유는 20mm다.

### 4.4 판정 규칙과 측정 시점

**판정 규칙** [제안]. h = z_s + d (측정한 하면 높이)다.

| 조건 | 판정 |
|---|---|
| RangeStatus ≠ 0, 신호율이 하한 미만, 측정범위 밖 | **'카세트 없음 또는 고장'.** 정지하고 작업자 확인을 기다린다. '비어 있음'으로 보지 않는다 |
| \|h − S(n)\| ≤ 5 | 가장 아래 웨이퍼 = 슬롯 n |
| \|h − H_ref\| ≤ 5 | 빈 카세트(기준면이 보임). H_ref는 현장에서 실측한다 |
| h < 185 | 슬롯 1 아래에 이물이나 포크가 있다. 알람 |
| 그 밖의 값 (예: 슬롯 사이, 271 < h < H_ref − 5) | 알람 |

- **'비어 있음'은 기준면이 읽힐 때만 인정한다.** 검정·반투명 웨이퍼, 센서 오염, 정렬 불량도 '신호 없음'을 낸다. 투입에서 아래 웨이퍼를 못 보고 위 슬롯으로 건너뛰면 충돌한다. R0 포크가 슬롯 웨이퍼와 17.5mm 겹친 채 올라가기 때문이다(`r9_geometry.py` 7행).
- **기준면.** OK는 클램프 윗판 아랫면을 쓴다(≈ 300.5 [가정]). IN/NG는 카세트 상부판이나 추가 반사판을 쓴다. 크기는 빔 지름 + 16mm 이상이다(z300에서 약 Ø87 [계산]). 기준면을 만들 수 없으면 DOCK-IN·DOCK-NG 스위치를 단다.
- **슬롯 건너뛰기는 자동으로 하지 않는다.** 작업자가 확인한 뒤에만 한다.
- **측정 유효 조건**
  - 팔이 그 스테이션에서 60° 이상 떨어져 있어야 한다.
  - 그 스테이션 방위에서는 R0이라도 무효다. 운반 웨이퍼 끝 r234.5가 z170.5에서 빔 범위(r228.7~242.3)에 들어온다 [계산].
  - I2C 통신은 모든 축이 정지했을 때만 한다(1.5 #9).

| 시점 (정지 창) | 센서 | 기대값 | 불일치하면 |
|---|---|---|---|
| 대기 120°, 단계 1 전 | IN | 가장 아래 = S(n) | 위 슬롯이면 작업자 확인. 신호 없음이면 `WAIT_INPUT` |
| 단계 6 촬영 정지 (팔 120°) | IN | S(n+1) 또는 기준면 (Δ = +18) | 여전히 S(n)인데 S4가 ON이면 이중 집기나 S4 오검출을 의심해 알람 |
| S4 없음 → R0(S3) → Z105 → 120°로 선회 → 측정 | IN | - | 여전히 S(n)이면 집기 실패이므로 재시도한다. S(n+1) 또는 기준면이면 웨이퍼가 포크에 있거나(S4 오검출) 떨어진 것이다. 작업자나 카메라로 확인한다 |
| 단계 6 (OK/NG 단계 9 전) | NG 또는 OK | 가장 아래 > S(k), 또는 기준면 | 슬롯 k가 이미 차 있다. 넣지 않는다 |
| 넣은 뒤 다음 정지 창 | NG 또는 OK | 가장 아래 = S(k) (Δ = −18) | 넣기 미확인 알람 |
| 작업자 교체 뒤 | 해당 센서 | 빈 카세트 = 기준면 | 이물 웨이퍼가 있으면 거부한다 |

- 단계 6 정지는 `CAPTURE_S` 0.5s다. 이 창에서 200ms × 2회면 센서 1개로 0.4s라서 사이클은 늘지 않는다 [계산].
- 센서 2개를 순차로 재면 +0.3s가 된다. 채널별로 동시에 측정을 시작하면 0.4s다. 동시 측정 간섭은 [추정]이므로 B13에서 확인한다.

### 4.6 TCA9548A와 측정 타이밍

- TCA9548A(0x70)는 버퍼가 아니라 pass-gate 스위치다(TI 데이터시트).
- 네 센서가 모두 0x29라서 **한 번에 한 채널만** 연다. 순서는 채널 선택 → 쓰기·읽기 → 0x00 쓰기(전 채널 끔)다.
- 측정 방식: 정지 창에서 single-shot 시작 명령을 보낸다. 변환이 끝나기를 기다리는 동안에는 I2C 통신을 하지 않는다. 결과 준비 비트를 확인한 뒤 결과를 읽는다.
- Pololu 라이브러리의 `readRange*` 계열은 블로킹이므로 운동 중에는 쓰지 않는다.
- 100kHz에서 레지스터 읽기 1회는 약 0.45ms다 [계산]. 5000 step/s의 펄스 간격은 0.2ms라서 운동 중에는 짧은 읽기도 스텝을 흔든다.

| 모드 | 타이밍 버짓 [기억값, ST UM2039] | 4개 순차 1바퀴 | 센서당 |
|---|---|---|---|
| High speed | 20ms | 약 92ms | 약 11Hz |
| Default | 33ms | 약 144ms | 약 7Hz |
| High accuracy | 200ms | 약 0.81s | 약 1.2Hz |

### 5.3 I2C (Mega + TCA9548A + VL53L0X ×4)

```
[control box, fixed]
 Mega SDA20/SCL21 --(<=15cm)-- TCA9548A (0x70, VIN 5V, RST <- pin 27)
                                 ch0 --(0.5~1m)-- TOF-IN   (input dock, below)
                                 ch1 --(0.5~1m)-- TOF-NG   (NG dock, below)
                                 ch2 --(0.5~1m)-- TOF-OK   (OK dock, below)
                                 ch3 --(0.5~1m)-- TOF-CART (cart seat, above)
```

- **분기 케이블.** LAN 4쌍 중 3쌍을 SDA/GND, SCL/GND, 5V/GND로 쓴다. SDA와 SCL을 한 쌍으로 꼬지 않는다. 5V와 꼬는 배선을 쓸 때는 양끝에서 5V–GND 사이에 100nF를 단다 [기억값: NXP UM10204 배선 지침, 원문 재확인]. 분기 길이는 [추정]이다.
- **상승시간** tr = 0.8473·Rp·Cb (NXP UM10204). 가정: 케이블 100pF/m, 소자 40pF. 상류 풀업은 Mega 10k [추정] ∥ Adafruit 10k ≈ 5kΩ이고, 모듈 풀업은 [불명]이다.

| 경우 | Cb | 모듈 풀업 없음 (5kΩ) | 모듈 10k 가정 (3.3kΩ) | 100kHz 한계 1000ns |
|---|---|---|---|---|
| 권장 (0.15 + 0.7m) | 125pF | 530ns | 350ns | 통과 |
| 분기 1.5m | 205pF | 870ns | 580ns | 통과 (여유 적음) |
| 팔 장착 (2.5m, 참고) | 305pF | 1290ns | 860ns | 불가 또는 경계 |

- 버스 속도는 **100kHz로 고정**한다.
- 풀업 최소값은 (5 − 0.4V) / 3mA = 1.53kΩ이다. 채널 쪽에 4.7k를 더하는 것은 A8에서 모듈 풀업을 잰 뒤, 합성값이 1.53kΩ 이상일 때만 한다.
- 전압은 TCA9548A VIN과 모듈 VCC 모두 5V로 통일한다. 모듈의 5V 동작(LDO, MOSFET 레벨변환)은 [추정]이다.
- Mega TWI 입력의 VIH 최소는 0.7·VCC = 3.5V다 [기억값: ATmega2560 데이터시트 TWI 특성표]. 일반 I/O는 0.6·VCC다. Mega 쪽 SDA/SCL 유휴 전압이 3.5V 미만이면 불가다.
- **SHT(XSHUT)와 GP1은 배선하지 않는다. SHT를 5V(VCC)에 직접 연결하지 않는다.**
  - VL53L0X의 XSHUT·GPIO1 절대최대정격은 3.6V다. 레벨변환 모듈도 보통 이 두 핀은 변환하지 않는다 [외부자료: ST 데이터시트, Pololu 2490].
  - 0x29가 응답하지 않으면 먼저 전원을 켠 상태에서 SHT 패드 전압을 잰다. 2.6~3.5V면 내부 풀업이 있다.
  - 풀업이 없으면 모듈 LDO 출력(2.8V/3.3V)에 10kΩ으로 풀업한다.
- 노이즈와 멈춤 대책
  - `Wire.setWireTimeout(25000, true)`를 쓴다(지원 코어 버전 [확인 필요]).
  - 에러가 나면 TCA9548A RST로 리셋한다.
  - 정지는 MCU와 무관한 하드웨어 경로(SMPS AC 스위치)로 한다.
  - 노이즈 시험에 실패하면 Plan B를 쓴다. 원격 Nano가 TCA와 ToF 4개를 맡고 메인과 UART(Serial2)로 통신한다. 다른 대안은 PCA9615 ×2다.

### 5.4 EE-SX670 결선과 극성 (전부 Light-ON)

| 센서 단자 | 연결 |
|---|---|
| + | 센서 전용 5V 레일. 24V로 급전하면 로직 GND와 24V GND가 묶여 스테퍼 입력의 옵토절연이 무력화된다 |
| 0V | 로직 GND |
| OUT | Mega 입력. 외부 풀업 4.7kΩ을 Mega 5V로 단다. 필요하면 1kΩ 직렬 + 10nF를 더한다 |
| L | EE-1001-1은 내부에서 L–+가 단락되어 Light-ON이 된다. EE-1001(Dark-ON)과 섞지 않는다. Dark-ON에서 L을 0V에 연결하면 안 된다 |

**센서별 논리와 고장 모드** (풀업 입력. 단선, 커넥터 빠짐, 센서 무전원은 모두 HIGH로 읽힌다)

| 센서 | 동작 상태 | 단선(HIGH)일 때 해석 | 안전 여부 |
|---|---|---|---|
| S2, S5, S6 (리밋형) | 차광 = HIGH = 리밋 | 리밋에 닿은 것으로 보고 정지 | 안전측 |
| S1, S10 (래치형) | 구간 차광 | 예정 엣지가 래치되지 않으면 알람. θ > +6인데 S1이 HIGH면 알람 | 검출 가능 |
| S9, S3, S7 (확인형) | 확인 = 투광 = LOW | '확인 안 됨'으로 보고 선회·다음 동작을 금지 | 안전측. 단, 띠가 빠지면 LOW가 되므로 S3·S7 동시 LOW를 불가능 조합으로 검사한다 |
| PWR24 (24V 감시) | 24V 없음 = HIGH | SMPS 꺼짐으로 보고 정지 | 안전측 |
| S4 | [확인 필요] | [확인 필요] | 3.4절 |

- **공통 전원 단선 감지.** 케이블 B의 5V가 끊기면 모든 입력이 HIGH가 된다. 다음 조합은 물리적으로 불가능하므로 즉시 정지한다.
  - S2와 S5가 동시에 차광
  - S2 차광인데 S9가 '108 초과'
  - S6·S1·S10이 모두 차광
  - S3와 S7이 동시에 투광(LOW). 띠 빠짐이다
- **OUT–GND 단락**(LOW 고정)은 '도그 없음' 또는 '확인됨'으로 읽힌다. S2 단락은 S9 기준 탐색 한도로 막는다(6절). S3·S7 단락은 R 기동 확인(0.5s, 3.3절)으로 잡는다.
- 전기 확인: 싱크 전류는 약 1mA라서 정격 100mA [기억값]보다 훨씬 작다. 응답 1kHz 이상 [기억값]이므로 지연 1ms는 60°/s에서 0.06°다.

## 6. 원점 시퀀스 [제안]

기존 순서(R 수축 → Z 최하단 → Z105 → θ 원점 → 대기 120°)는 유지한다. 원점 제한시간은 축별로 나눈다. Z는 50s, θ는 22s다. 현행 `HOMING_TIMEOUT_S` 30s는 전체 원점에 대한 값이라 Z 최악 경우(약 44s)를 넘는다.

| 단계 | 동작 | 속도 / 판정 |
|---|---|---|
| H0 | 움직이지 않고 점검한다. PWR24(24V 있음)와 AL×2 정상을 확인한다. 공기가 끊겼던 이력이 있으면 후진 코일로 스풀을 후진에 둔 뒤 공기를 넣는다. 불가능 조합(5.4절)이면 정지한다. S5나 S6가 차광이면 작업자 조그로 넘긴다. 카세트를 든 채(T5~T10) 정전된 기록이 있으면 작업자가 수동으로 회수한다 | - |
| H1 | R을 후진한다(후진 코일 ON) | S3 LOW, S7 HIGH. 4s 안에 확인되지 않으면 알람. S3·S7 동시 LOW면 즉시 정지 |
| H2a | **S2가 이미 차광일 때.** S9가 투광(Z ≤ 108)으로 확인될 때만 위로 1mm/s 이탈한다. S2가 투광이 되고 1mm 더 간 곳에서 멈춘다. 한도는 Z108까지다. Z108 아래에서는 포크 윗면이 173.5 이하라서 어느 방위에서도 충돌하지 않는다 [계산]. S9가 없으면 한도는 2mm다(최소 위 여유 3.0mm보다 작게). 한도 안에 투광이 안 되면 움직이지 않고 'S2 고장 의심' 알람을 낸다 | 1mm/s |
| H2b | 하강한다. S9가 '108 초과'면 5mm/s로 S9 투광(Z108)까지 내려간다. 그다음 2mm/s로 S2 차광까지 내려간다(지나침 0.18mm). S9 이후 14mm 안에 S2가 차광되지 않으면 정지하고 알람을 낸다 | S9가 없으면 AL 배선을 전제로 5mm/s |
| H2c | 위로 1mm/s 이탈한 뒤 0.5mm/s로 다시 내려간다. **투광→차광 순간을 래치**해 Z = 95로 정한다 | 0.5mm/s |
| H3 | Z105로 이동한다 | S9 투광을 확인 |
| H4 | θ 원점. 3.1절 판정표로 방향을 정한다. 빠르게(25°/s) 접근하고, 엣지를 3° 넘을 때까지 반대로 이탈한다. 2°/s로 **− 방향 재접근**하며 S1 투광→차광을 래치한다. θ를 +3 + `θ_HOME_OFS`로 정한다. 탐색 중 S6가 차광되면 즉시 정지하고 알람 | 빠름 지나침 0.156·i deg [계산]. 최대 탐색 300° |
| H5 | 대기 120°로 이동한다 | S10 +90 엣지 기준값 확인 |
| 운전 중 | S1·S10 통과 래치를 판정한다(3.1절). 선회 전에는 S3 LOW·S7 HIGH(동시 LOW면 즉시 정지)와 S9 LOW를 확인한다. R 전진 코일은 3.3절 인터록을 만족할 때만 켠다. ToF는 정지 중에만 통신한다 | \|Δ\| > 0.5°면 `S1_MISMATCH` |

남는 위험: S2가 GND와 단락된 채 Z ≤ 95에서 전원을 켜면, 2mm/s로 바닥에 닿을 수 있다. 이 경우는 AL로 멈춘다(AL 배선이 전제).

## 검토 메모

- high 이슈 가운데 무시한 것은 없다. ToF 정확도, SHT 5V, H2 상승 이탈, S3 극성, S7 필수를 모두 반영했다.
- 'S4 없음' 뒤 TOF-IN을 읽는 방법이 검토 의견끼리 달랐다. 'R0 그 자리에서 측정' 대신 '120°로 선회한 뒤 측정'을 골랐다. 포크에 웨이퍼가 있으면 끝 r234.5가 빔 범위(r228.7~242.3)에 들어오기 때문이다 [계산].
- '연속 모드로 운동 중에 읽기' 대안은 채택하지 않았다. 레지스터 읽기 1회(약 0.45ms)가 5000 step/s의 펄스 간격(0.2ms)보다 길기 때문이다.
- S9는 검토 의견(같은 도그 아래끝, Z ≤ 108에서 차광)과 극성을 반대로 정했다. 그 안은 단선을 'Z ≤ 108'로 오인한다.
- 초안 9절(검토안 간 충돌표)은 지우고, 선택 근거는 해당 절에 한 줄씩 넣었다.
- 5절과 8.2절을 부록으로 옮기라는 의견은 '1~8 구성 유지' 지시에 따라 본문에 두고 줄였다.
