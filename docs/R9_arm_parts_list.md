- **EE-SX670 결선:** 모두 Light-ON(EE-1001-1), 5V 전원, 외부 풀업 4.7kΩ. 단선되면 HIGH로 읽혀 안전한 쪽으로 동작한다.

## 2. 구매 리스트

### A. 센서·전장
| 품목 | 수량 | 비고 |
|---|---|---|
| **Omron EE-SX670** | **9** | 필수 4 + 권장 4 + 예비 1. **반품 불가** |
| **Omron EE-1001-1** (Light-ON 커넥터) | **9** | 케이블 없는 커넥터 단품. 4심 전선을 따로 준비. 대안: 프리와이어 EE-SX670-WR (모델명 [확인 필요]) |
| SEENGREAT VL53L0X 모듈 | 4 | 5V 동작 여부 [확인 필요]. SHT 핀은 5V에 연결 금지 |
| Adafruit TCA9548A (2717) | 1 | ch0~3 사용 |
| 24V 감시: PC817 + 저항 (또는 분압 저항) | 1식 | Mega A10 |
| R 밸브 구동: SPDT 릴레이 1 + 옵토 MOSFET 1ch + 플라이백 다이오드 + 10kΩ 풀다운 2 | 1식 | 두 코일이 동시에 켜지지 않게 하드웨어로 막음 |
| 풀업 4.7kΩ, RC 1kΩ/10nF, 100nF | 입력 수만큼 | |
| 센서 전용 5V 전원 (1A 이상) + 폴리퓨즈 0.75~1A | 1 + 1 | 센서 합계 약 420mA, 피크 약 500mA |

## 4. 약점과 미결정 사항

| # | 내용 | 할 일 |
|---|---|---|
| 1 | **SMPS를 꺼도 R(실린더)은 멈추지 않는다** | 수동 차단·배기 밸브를 손 닿는 곳에 둔다 |
| 2 | **SMPS를 끄면 Z가 떨어질 수 있다** | 카세트를 든 상태(Z241)에서 끄고 10초 하강 ≤ 0.5mm 확인 (B27) |
| 3 | **전원이 돌아오면 하던 동작이 이어질 수 있다** | PWR24로 감지해 이동 취소, 밸브 OFF, 원점 복귀 요구. 자동 재시작 금지 |
| 4 | **R85(대차 적재)를 할 수 없다** | 대안 A(받침을 당기고 대차 물러남 인터록) 또는 B(직렬 2단)를 A6 실측 뒤 선택 |
| 5 | 하부 ToF의 슬롯 판정 성능이 검증되지 않았다 | 시험 B13~B15. 도크·카세트 바닥이 열려 있어야 함 |
| 6 | θ 도그 3층이 들어갈 공간 | 피니언~원판 틈 g 실측 (A2) |

**[불명]:** SMPS 모델·스위치 유무, 아두이노 전원(USB/SMPS), 리드스크루 자체 잠김, 밸브 코일 전압, 가이드 유무, 두 번째 실린더 행정, ToF 모듈 5V 동작, 제어기 기종.
