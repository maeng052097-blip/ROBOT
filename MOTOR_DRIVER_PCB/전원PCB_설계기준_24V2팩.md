# 전원분배 PCB 설계기준 — 24V 2팩 구성 (2026-09-03)

MOTOR_DRIVER_PCB 하위. 이전 문서(`전원분배_설계검증.md`, `전원분배_36V단일팩_검증2.md`)의
36V 단일팩 / 24V+36V 2팩 안을 **대체**한다. 그 문서들의 안전 원칙(BMS/워치독/스타접지)은 유효하다.

---

## 0. 아키텍처

```
[24V 10Ah 팩A] - SW_A - F1(30A) - PCB-A -+- MDD10A #1 - 바퀴 M1, M3
                                         +- MDD10A #2 - 바퀴 M2, M4
                                         +- 24V->12V 벅 - 냉각팬 x2
                                         +- 타워램프 24V (릴레이 4채널, 7-5 참조)
                                         +- 볼트미터

[24V 10Ah 팩B] - SW_B - F2(10A) - PCB-B -+- 스테퍼 x3 (각 5A 고속퓨즈)
                                         +- XL4016 #1 -> 7.4V -> PCB-B -> DRS-0201
                                         +- XL4016 #2 -> 12V  -> PCB-B -> DRS-0601
                                         +- 볼트미터

[노트북 USB] - 5V - Arduino Mega + MEGA_SHIELD
```

배터리: VOLTON 24V 10Ah 리튬이온, 7S. 만충 29.4V / 공칭 25.9V / 방전말 21.0V.
BMS 연속 20A, 1초 차단 60A. 방전단자 **XT60 암(F)** -> 보드는 수(M). (7-1 참조)

**2팩으로 나눈 이유**: 바퀴의 서지 전류가 팔 전원을 흔들지 않게 분리.

## 1. 근본 원인 규명 (이번 설계의 출발점)

**MDD10A 손상 원인 = SMPS + 회생전류.** (2026-09-03 확정)

SMPS는 전류를 흘려보내기만 하고 **받아들이지 못한다**. 감속 시 모터가 밀어낸 전류가
출력 커패시터로만 들어간다.

```
25kg @ 0.5m/s 운동에너지 = 3.1J
SMPS 출력캡 2200uF 가정:
  0.5 * C * (V^2 - 24^2) = 3.1   ->   V = 58.3V
MDD10A 절대상한 30V   ->   즉사
에너지의 10%만 들어와도 29.3V (이미 한계)
```

증상 4개가 이것 하나로 설명된다:

- 무부하 40~50도 = 손상된 하프브리지의 관통전류(부하 무관)
- 양방향 LED 동시 점등 = MOSFET 부분 단락
- 2개 구동 시 속도 저하 = SMPS OVP 히컵(셧다운/재시작)
- 보드 교체 후 재발 = 원인이 그대로라 새 보드도 같은 방식으로 죽음

**배터리는 전류를 받아들인다(충전).** 전압 상승 = I_회생 x 팩내부저항 = 약 5A x 80mohm = **0.4V**.
58V 대 0.4V — 차원이 다르다.

드라이버 교체 완료(2026-09-03). 전원을 배터리로 전환하면 원인이 제거된다.

## 2. 운용 규칙 (전기적 근거 있음 — 지키지 않으면 설계가 무효)

### 2-1. 완충 금지 — 27V(약 80%)까지만

이유 두 가지. 둘 다 치명적이다.

| # | 이유 |
|---|---|
| 1 | 만충 29.4V + 회생 0.4V = **29.8V**. MDD10A 한계 30V. 여유 0.2V |
| 2 | **BMS가 만충이면 충전 FET을 닫는다.** 그 상태에서 회생 전류가 들어오면 BMS가 막는다 -> 배터리가 회로에서 사라진 것과 동일 -> **SMPS와 똑같은 상황** |

27V로 운용하면 마진 3V. 부수효과로 리튬이온 수명도 늘어난다(만충 보관이 열화 주범).

### 2-2. 전원 인가 순서

쉴드에 **풀다운 저항이 하나도 없다**(부품 실측: 커넥터와 마운팅홀뿐).
아두이노가 꺼진 상태에서 MDD10A 입력이 플로팅되면 모터가 임의로 돌 수 있다.

```
켤 때:  1. 노트북 USB 연결
        2. 부팅 메시지 확인
        3. 스위치 A, B (순서 무관)

끌 때:  역순 (스위치 먼저, USB 나중)
```

`setup()` 이 `digitalWrite(DIR, LOW)` + PWM 듀티 0 을 설정한 뒤에 전원이 들어가야 한다.

**풀다운 대안(보드 수정 없이)**: MDD10A 5핀 SPOX 하우징 안에 10k 저항을 크림프로 끼워
DIR/PWM 을 같은 커넥터의 GND 핀으로 내린다. 채널당 2개, 보드당 4개, 총 8개.

### 2-3. 볼트미터는 반드시 스위치 하류

```
소비 5~15mA   ->   10Ah / 10mA = 1000시간 = 41.7일
```

상시 연결하면 팩이 과방전으로 죽는다.

## 3. GND 토폴로지 (설계의 핵심)

### 3-1. 스타점 = 아두이노 쉴드 GND존

쉴드 실측: GND는 **F.Cu + B.Cu 양면 존 채움**, 100.2~201.4 x 32.9~113.7mm.
연결 패드 = MD1.5, MD2.5, ST1/2/3.8, HK1.3, ENC1~4.2, J7.1/2, J1.6/7, J2.4.

```
팩A 음극 - 굵은선 - PCB-A GND - MDD10A x2 전원GND        [여기서 끝]
팩B 음극 - 굵은선 - PCB-B GND -+- 스테퍼 x3 V-
                              +- XL4016 x2 입력- / 출력- (비절연이라 같은 노드)
                              +- 서보 2개 GND (7-4b)

쉴드 GND존 -+- MD1.5 / MD2.5   (SPOX, 팩A 도메인과의 유일한 다리)
            +- HK1.3           (팩B 도메인과의 유일한 다리)
            +- ST1/2/3.8       (AL-, 옵토면 전원과 무관)
            +- ENC1~4.2
            +- 노트북 USB GND
```

각 팩의 전류는 **자기 팩 안에서 닫힌다**. 쉴드가 나르는 것은 엔코더 복귀 + 알람 +
TTL + 드라이버 입력 바이어스뿐 — 전부 mA급.

### 3-2. 버스바 안(안2)을 폐기한 이유

MDD10A는 **비절연** — 신호 GND(5핀 커넥터 5번)와 전원 GND가 내부에서 공통이다.
버스바로 두 팩 음극을 묶으면 병렬 경로 = 루프가 생긴다.

```
경로1: MDD10A 전원GND - 12AWG 500mm - PCB-A - 버스바 - 팩A-       약 5 mohm
경로2: MDD10A 신호GND - SPOX - 쉴드 - 아두이노 - 본딩선 - 버스바   약 33 mohm

분류비 = 5/(5+33) = 13%
4륜 스톨 40A x 13% = 약 5A 가 SPOX 커넥터로 흐름
```

**Molex SPOX 5267 정격 = 접점당 3.0A.** 1.7배 초과 -> 커넥터가 녹는다.

참고: 노트북 USB는 어느 배터리 음극에도 묶여 있지 않아 루프가 USB로 닫히지 않는다.
USB는 피해자가 아니다. 피해자는 SPOX 커넥터다.

### 3-3. 예비 GND선

안1의 유일한 고장모드: MD1.5/MD2.5 GND선이 끊기면 MDD10A 로직 기준이 사라져
**모터가 예측 불가로 돌 수 있다.**

대책: PCB-A GND 단자에서 쉴드 GND로 예비선 1가닥. 두 선이 **같은 지점**에서 출발하면
루프 면적이 0이라 3-2의 문제가 생기지 않는다.

## 5. 퓨즈

| 위치 | 값 | 근거 |
|---|---|---|
| 팩A 메인 | **30A ATO 블레이드** | 스톨 40A에서 30~100초 후 용단(스톨감지가 먼저 정리). 단락 보호 |
| 팩B 메인 | **10A ATO 블레이드** | 실부하 약 2A |
| 스테퍼 각 1개 | **5A 고속퓨즈** | 드라이버 매뉴얼 7.1절 명시 권장 |

ATO 정격 **32VDC** > 만충 29.4V — 24V 구성이라 쓸 수 있다. (36V안이었으면 불가)
위치: 배터리 단자에서 150mm 이내, **스위치 상류**.

**퓨즈가 막는 것 = 배선 단락.** 모터 과전류는 BMS 담당. BMS가 있어도 퓨즈가 필요한 이유:
경성 단락에서 퓨즈가 더 빠르고, **BMS MOSFET이 닫힌 채 고장**나면 퓨즈만 남는다.

## 6. 스위치 / E-stop

- **팩별 스위치 2개.** 팩A 40A급, 팩B 15A급. 각 팩 옆에 배치해 배선을 짧게.
- **E-stop = 릴레이 방식** (자율주행 시험 전 필수)
  - 40A 자동차 릴레이 2개 + E-stop 버튼(소전류)
  - 코일을 각 팩에서 따고 **버튼을 직렬**로 -> 누르면 양쪽 동시 개방
  - 40A DPST 토글(2~3만원)보다 싸고 작다
  - 주의: 코일 상시 소비 약 150mA x2. 끄는 것을 잊으면 방전

펌웨어 `ESTOP` 명령은 펌웨어가 살아 있어야 동작한다. 물리 E-stop이 그 백업이다.

## 7. PCB 설계 기준

### 7-1. 공통

- **2층, 2oz(70um) 구리**
- 전원 경로는 트레이스가 아니라 **폴리곤 pour**
- 역극성 방지: XT60은 극성이 고정되지만 단자대는 실수 가능 -> 실크에 극성 대문자 표기

**배터리 입력 커넥터 (2026-09-03 확정)**

VOLTON 팩의 방전단자 사진 확인 결과 **구멍 2개가 빈 소켓** = **암(Female)**.
-> 보드에는 **수(Male)** 를 단다.

```
풋프린트: Connector_AMASS:AMASS_XT60-M_1x02_P7.20mm_Vertical
```

XT60 정격 60A 연속이라 팩A 최악 44A 를 커버한다.
역극성 보호 회로를 넣지 않는 이유: 40A 직렬 다이오드는 `0.5V x 40A = 20W` 손실이라
불가능하고, XT60 이 극성을 물리적으로 강제하므로 회로가 불필요하다.

★실물 재확인법: 구멍 안에 금색 핀이 튀어나와 있으면 수(M) -> 보드는 암(F) 로 바꿔야 한다.
빈 통(소켓)이면 암(F) -> 지금 설정(수) 그대로.

### 7-2. 트레이스 폭 (IPC-2221, 외층, dT=20도, 2oz)

| 전류 | 필요 폭 |
|---|---|
| 40A | 16.1 mm |
| 30A | 11.0 mm |
| 20A | 6.6 mm |
| 10A | 3.0 mm |
| 1A | 0.3 mm |

**설계값**: PCB-A 전원 폴리곤 최소폭 **8mm**(20A 연속 기준), 입력부는 **M4 볼트 단자**.
스톨 40A는 퓨즈와 스톨감지로 제한되는 단시간 조건이므로 연속 40A로 설계하지 않는다.
PCB-B는 최대 10A(퓨즈 상한) -> 폴리곤 3mm면 충분.

| VOLT_METER | 0.015A | SPOX |
| VBAT_SENSE 출력 | 0.25mA | SPOX |

### 7-4b. 서보 전원 경로 — 벅 출력을 반드시 보드로 되받는다 (2026-09-03 추가)

**초기 설계 누락이었다.** XL4016 '입력(24V)'만 보드에 있고 출력(7.4V/12V)이
보드로 돌아오지 않아, 서보 GND 가 PCB-B 의 단일 GND 폴리곤에 붙지 못했다.

```
+24V_B --> J6.1  [XL4016 #1]  J6.3 --> SERVO_7V4 --> J10 --> DRS-0201
   GND --> J6.2                J6.4 --> GND

+24V_B --> J7.1  [XL4016 #2]  J7.3 --> SERVO_12V --> J11 --> DRS-0601
   GND --> J7.2                J7.4 --> GND
```

**왜 되받아야 하나**: XL4016 은 **비절연**이라 `OUT- = IN- = GND` 다.
출력을 보드에 물려야 서보 GND 가 3-1 절의 스타 토폴로지 안에 들어온다.
벅 출력에서 서보로 직결하면 GND 가 보드 밖에서 갈라져 접지 설계가 깨진다.

**부수 효과**: 두 벅의 출력 GND 가 같은 노드가 되므로 **서보 2개의 GND 가 자동으로 공통**
이 된다. 허큘렉스 멀티드롭 TTL 의 필수 조건(GND 공통)이 배선 실수 없이 보장된다.
전압이 7.4V / 12V 로 달라도 TTL 레벨은 서보 내부 5V 레귤레이터에서 나오므로 무관하다.

★TTL(TXD/RXD)은 이 보드를 거치지 않는다. 쉴드 `HK1` 에서 서보로 직접 간다.
PCB-B 는 전원만 담당한다.

### 7-4c. XL4016 사용 절차 (★순서를 틀리면 서보가 즉사한다)

XL4016 은 **조정형**이다. 출고 상태의 출력 전압은 임의 값이라, 서보를 먼저 물리면
24V 가 그대로 들어가 **DRS-0201(정격 7~12V)이 즉사**한다.

```
1. 서보를 연결하지 않은 상태로 XL4016 에 24V 만 인가
2. 출력 단자에 멀티미터
3. 포텐셔미터를 돌려 7.4V(#1) / 12.0V(#2) 로 맞춤
4. 전원 끄고 포텐셔미터를 락타이트/실리콘으로 고정
5. 전원 재인가 후 전압 재확인
6. 그 다음에 서보 연결
```

★4번을 건너뛰지 말 것. 로봇은 계속 진동한다. 포텐셔미터가 돌아가면 출력이 올라가 서보가 죽는다.

**발열은 정격이 아니라 스톨 때문에 생긴다:**

| | 정격 | 스톨 |
|---|---|---|
| #1 (24->7.4V) | 0.67A = 5W, 손실 약 1.3W | 추정 7A = 52W, **손실 약 13W** |
| #2 (24->12V) | 약 1A = 12W, 손실 약 3W | 실측 필요 |

정격에서는 뜨겁지 않다. 서보가 물체를 물고 버틸 때가 문제다.
-> **방열판 + 통풍 확보. 밀폐 금지.** 대차 후면 팬 근처가 좋다.

**입력 전압 여유**: XL4016 입력 8~40V, 24V 팩 만충 29.4V -> 여유 10.6V.
※ 36V 안을 폐기한 이유이기도 하다 — 36V 만충 42V > 40V 라 XL4016 이 파괴된다.

### 7-5. 타워램프 구동 — 외부 릴레이 모듈 + 온보드 ULN2003 (확정 2026-09-03)

24V는 아두이노가 직접 못 켠다. 그리고 **램프 제품이 미정이다.**

MOSFET 로우사이드 스위칭은 **공통 + 부하**에서만 동작한다. 타워램프는 제품마다
공통선이 +인지 -인지 다르므로 MOSFET은 도박이다. **릴레이 접점은 극성 무관**하고
공통+ / 공통- / DC / AC 를 전부 수용하므로, 램프 미정 상태에서 유일하게 안전한 선택이다.

**릴레이는 코일과 접점이 전기적으로 분리된 부품**이라는 점이 핵심이다.
코일 12V 는 릴레이를 '누르는' 데만 쓰이고, 램프에는 24V 가 그대로 지나간다.

```
[램프 회로 - 24V]
PCB-A 24V --> K1 COM --(접점)-- K1 NO --> 타워램프 색선
PCB-A GND <---------------------------- 램프 공통선

[코일 회로 - 12V]  ... 위와 전기적으로 완전 별개
쉴드 D42 --> ULN2003 IN1 --> OUT1(오픈컬렉터) --> 모듈 IN1 --> 코일 --> GND
```

#### 확정 모듈: NEROMART RELAY-M1(CH4)-12V (NER-11351)

AVRMALL 상품번호 1280370. 17,600원(VAT 포함). 국내 제조, 준비 2~3일.
**회로도(PDF) 제공** — 이것이 선정 이유다. 저가 OEM 품은 데이터시트가 없어
받아서 측정해야만 알 수 있다.

회로도에서 확인한 실제 구성:

| 부품 | 실체 |
|---|---|
| 옵토커플러 | **TLP181GB** x4 (도시바) |
| 스위칭 TR | MMBT3904 x4 |
| 플라이백 다이오드 | **1N4148 x4** (모듈 내장) |
| 입력 저항 / 베이스 저항 | 1kohm / 510ohm |
| JD-VCC 점퍼 | **JP1 (HEADER 1x2)** |
| 제어 헤더 | **JP2: 1=GND 2=IN1 3=IN2 4=IN3 5=IN4 6=VCC** |
| 릴레이 | 한국릴레이 HR702N (SPDT) |
| 출력 단자 | JK300-500-3P x4 (NC/COM/NO, 5.0mm 피치) |
| 접점 정격 | AC 10A 120V / 6A 250V, **DC 10A 24V** |
| 크기 / 무게 | **72 x 63mm** / 66g |

입력부는 **직렬** 구조다: `VCC - R1(1K) - [TLP181 LED, Vf 1.2V] - [녹색 LED, Vf 2.0V] - IN`

#### ULN2003 이 필요한 이유

모듈 사양에 **"입력 신호 9V~12V"** 라고 명시돼 있다. 회로도로 계산하면 그 이유가 나온다.

```
아두이노가 HIGH(5V) 출력 시:
  LED 양단 = 12V - 5V = 7V,  Vf 3.2V 빼면 R1 에 3.8V
  I = 3.8mA  ->  TLP181 은 1~5mA 면 켜짐  ->  릴레이가 안 꺼진다

아두이노 핀을 INPUT(하이임피던스)로 둬도 안 된다:
  12V -> R1 -> LED -> IN -> 아두이노 ESD 클램프 다이오드 -> 5V 레일
  IN 이 약 5.6V 로 클램프,  I = (12-3.2-5.6)/1k = 3.2mA  ->  여전히 켜짐
  게다가 그 전류가 아두이노 5V 레일로 역주입된다
```

**ULN2003 = 오픈컬렉터 7채널 달링턴 드라이버(50V 내압).** 5V 로직을 받고,
OFF 시 출력이 진짜 오픈이 되어 모듈 IN 이 12V 까지 자유롭게 올라간다.

| 항목 | 값 |
|---|---|
| 부품 | ULN2003A **DIP-16 1개** (~500원). 모듈이 아니라 칩이다 |
| 사용 채널 | IN1~IN4 (핀 1~4) / OUT1~OUT4 (핀 16,15,14,13) |
| GND | 핀 8 |
| **COM (핀 9)** | **미연결.** 모듈에 1N4148 플라이백이 이미 있다 |
| 싱크 여유 | 500mA 능력 / 필요 8.8mA = 57배 |
| 디커플링 | 0.1uF |

**펌웨어 논리 (정상 논리):**
```cpp
digitalWrite(42, HIGH);  // ULN2003 IN=H -> OUT 싱크 -> 모듈 IN=0V -> 릴레이 ON
digitalWrite(42, LOW);   // OUT 오픈      -> 모듈 IN=12V -> 릴레이 OFF
```
부팅 시 아두이노 핀 기본값이 INPUT(부동) -> ULN2003 입력 LOW -> **릴레이 전부 OFF**(페일세이프).

#### 대안 (부품을 더 줄이고 싶을 때)

모듈 JP1 점퍼를 뽑고 **VCC=5V / JD-VCC=12V** 로 분리하면 ULN2003 없이도 동작한다.
다만 옵토 전류가 `(5-3.2)/1k = 1.8mA` 로 떨어져 마진이 2~4배뿐이고,
녹색 LED 의 Vf 가 3.0V(InGaN)면 0.8mA 까지 내려가 위험하다. **ULN2003 을 넣는 쪽으로 확정.**

#### 미사용 채널

4채널로 과잉설계한다(3색 + 부저 상정). 2색 램프면 IN3/IN4 를 안 쓰면 된다.
ULN2003 은 7채널이라 어차피 3채널이 남는다.

#### 확인 필요

회로도의 릴레이 품번이 `HR702NHDC05V`(5V) 인데 판매 사양은 `HR702NHDC12V` 다.
2015년 도면을 재사용하면서 품번을 안 고친 것으로 보이나, **주문 시 확인할 것.**
받으면 릴레이 몸체 인쇄로 5초면 확인된다.

## 9. 펌웨어 — 쉴드 장착 전 반드시 수정

**현재 사용 중**: `urt/mecanum_motor/src/main.cpp`
(`ROBOTBOT/tonghap-py/urt/mecanum_motor/src/main.cpp` 와 바이트 동일)

```
PWM_PIN = {5, 6, 7, 8}        Timer3(OC3A) + Timer4(OC4A/B/C)
DIR_PIN = {22, 23, 24, 25}
ENC_A   = {2, 3, 18, 19}      A상만. B상 미사용
PWM_TOP = 4095   ->   16,000,000 / 4096 = 3906.25 Hz   (3.9kHz 확인됨)
```

### 9-1. 충돌

| | 현재 펌웨어 | 쉴드 배선 |
|---|---|---|
| PWM | D5, D6, D7, D8 | D11, D12, D44, D45 |
| DIR | **D22, D23, D24, D25** | D34, D35, D36, D37 |

**D22~D25는 쉴드에서 스테퍼 ST1/ST2 의 PU-/DIR- 다.**
그대로 꽂으면 PWM은 아무 데도 안 가서 모터가 안 돌고, DIR은 **스테퍼 옵토에 들어간다.**

### 9-2. 수정 내용 (3군데). `PWM_TOP=4095` 는 그대로 두면 3.9kHz 유지

```cpp
// 36~37행
const uint8_t PWM_PIN[N] = {11, 44, 12, 45};
const uint8_t DIR_PIN[N] = {34, 36, 35, 37};

// setupPwm3900Hz()  Timer3/4 -> Timer1/5
TCCR1A = _BV(COM1A1) | _BV(COM1B1) | _BV(WGM11);
TCCR1B = _BV(WGM13)  | _BV(WGM12)  | _BV(CS10);
ICR1 = PWM_TOP; OCR1A = OCR1B = 0;
TCCR5A = _BV(COM5B1) | _BV(COM5C1) | _BV(WGM51);
TCCR5B = _BV(WGM53)  | _BV(WGM52)  | _BV(CS50);
ICR5 = PWM_TOP; OCR5B = OCR5C = 0;

// writePwm()
case 0: OCR1A = ocr; break;   // D11
case 1: OCR5C = ocr; break;   // D44
case 2: OCR1B = ocr; break;   // D12
case 3: OCR5B = ocr; break;   // D45
```

엔코더: `ENC_A = {2,3,18,19}` -> 쉴드는 `{3,18,19,20}`. **D2 가 D20 으로 바뀐다.**
쉴드에 B상(D30~D33)이 배선돼 있으나 현재 펌웨어는 A상만 쓴다(동작에는 지장 없음).

**쉴드 장착 후 `INVERT` / `POS_TO_MOTOR` 를 `M 1 50` ~ `M 4 50` 로 재실측해야 한다.**
두 펌웨어의 값이 서로 다르다.

### 9-3. 스톨 감지 (선택, 3단계)

현재 펌웨어에는 속도 측정 자체가 없다(`count[N]` 만 존재). 약 20줄 추가 필요.

| 단계 | 동작 |
|---|---|
| 1. 로그만 | `STALL i` 시리얼 출력. **정지 안 함**. 위험 0 |
| 2. 해당 축만 정지 | |
| 3. 전체 정지 + 자율해제 | 자율주행 본격 운용 전 |

스톨 시 duty 200에서 모터당 10.1A, 4륜 40A. 모터 권선 189W -> 절연한계까지 1~2분.
BMS(연속 20A) 차단 시 회생이 갈 곳을 잃는다 -> **7-7 벌크캡의 존재 이유.**

### 10-1. AL 절연 문제가 해소된 이유 (2026-09-03)

초기에 "AL이 비절연이면 SPOX 커넥터에 3A가 흘러 정격(3.0A)을 초과한다"고 판정했으나,
그 계산은 **상전류 2.5A를 입력전류로 오산**한 결과였다. 4-2에서 정정한 실제 입력전류로
다시 계산하면:

```
[정정 전 - 오류]  7.5A  x 10.5mohm = 79mV   ->  79mV / 26mohm = 3.0A   (정격 한계)
[정정 후 - 실제] 0.35A x 10.5mohm = 3.7mV  ->  3.7mV / 26mohm = 0.14A  (정격의 1/21)
```

**절연 여부와 무관하게 안전하다.** AL 측정은 편할 때 하면 되고, 어느 쪽이 나와도
설계가 바뀌지 않는다.

**레이아웃으로 한 번 더 방어**: PCB-B의 GND를 **단일 폴리곤**으로 만들고
스테퍼 V- 3개와 XL4016 입력- 2개를 **전부 같은 폴리곤**에 붙인다. 그러면 쉴드가 잇는
두 지점(AL- 경로 / HK1.3 경로)이 같은 노드가 되어 강제 전류가 0이 된다.
